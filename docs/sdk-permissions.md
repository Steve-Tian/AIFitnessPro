# SDK 及权限使用说明

> 国内应用市场上架时，通常需要在后台填写"权限使用说明"和"第三方 SDK 清单"。以下内容可直接复制填写。

---

## 一、权限使用说明

| 权限名称 | 权限标识 | 使用目的 | 是否必须 |
|---|---|---|---|
| 网络访问权限 | `android.permission.INTERNET` | 用于将训练数据同步至服务器、加载动作演示图片 | 是 |

**说明**：本应用仅申请上述 1 项权限，不申请摄像头、麦克风、位置、联系人、存储、电话等任何敏感权限。

---

## 二、第三方 SDK 清单

本应用使用以下开源库，均无独立隐私政策要求、不收集用户个人信息：

| SDK / 库名称 | 版本 | 用途 | 官方主页 |
|---|---|---|---|
| Jetpack Compose | BOM 2024.12.01 | Android UI 框架 | developer.android.com |
| Jetpack Navigation Compose | 2.8.5 | 页面路由与导航 | developer.android.com |
| Jetpack Room | 2.6.1 | 本地训练数据存储（SQLite 封装） | developer.android.com |
| Jetpack DataStore | 1.1.1 | 用户偏好设置持久化 | developer.android.com |
| Coil | 2.7.0 | 动作演示图片加载与缓存 | coil-kt.github.io/coil |
| Kotlin Serialization | 1.7.3 | 网络数据序列化/反序列化 | kotlinlang.org |
| Kotlin Coroutines | 1.9.0 | 异步操作与线程调度 | kotlinlang.org |

**说明**：以上所有库均为设备端运行的开源组件，无独立 SDK 隐私协议，不向第三方服务器上报任何用户数据。本应用不集成任何广告 SDK、推送 SDK、统计分析 SDK（如友盟、Firebase）。

---

## 三、数据出境说明

本应用的服务器部署于中国境内，用户数据不出境，无需填写数据出境相关申报材料。

---

## 四、个人信息收集清单（满足合规要求）

| 信息类型 | 具体内容 | 收集场景 | 是否必须 |
|---|---|---|---|
| 基本身体信息 | 性别、年龄、身高、体重 | 用户主动填写 Onboarding 表单时 | 是（用于生成计划） |
| 健身目标 | 增肌/减脂/塑形等选项 | 用户主动填写 Onboarding 表单时 | 是（用于生成计划） |
| 训练记录 | 动作名称、组数、重量、次数、完成时间 | 用户完成每次训练时自动记录 | 是（核心功能） |
| 设备信息 | 系统版本（用于日志排查） | 应用运行时自动获取 | 否（可不填） |

本应用**不收集**：手机号、身份证、位置信息、通讯录、图片/文件、支付信息、生物特征（人脸/指纹）。
